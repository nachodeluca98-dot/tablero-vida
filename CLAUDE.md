# Tablero de Vida

App personal (Next.js 14 + Prisma/PostgreSQL, deploy en Vercel) con bot de Telegram.

## Módulos
- Vehículos: especificación y decisiones en `docs/modulo-vehiculos.md`. Código en `src/lib/vehiculos/`, página `/vehiculos`, API `/api/vehiculos`.
- Finanzas: especificación y decisiones en `docs/modulo-finanzas.md`. Código en `src/lib/finanzas/`, página `/finanzas`, API `/api/finanzas`.
- Supermercado: especificación y decisiones en `docs/modulo-supermercado.md`. Código en `src/lib/supermercado/`, página `/supermercado`, API `/api/supermercado`, script `scripts/coto-carrito.ts` (corre en GitHub Actions).
